# 用户预设库(长期积累:场景 → 算法/参数)

这是**长期目标**的落地位置:每遇到一个新场景(问学长、问 AI、自己实测),
就把验证过的一组增强参数存成一个 JSON 放在这里,工作台启动时自动并入
"场景预设"下拉框,重名时覆盖内置预设。

## 文件格式(与工作台导出的"当前预设 JSON"完全一致)

```json
{
  "name": "夜间哨兵(实拍验证)",
  "imgsz": 640,
  "values": {
    "hsv_v": 0.8,
    "hsv_s": 0.6,
    "degrees": 5.0,
    "scale": 0.7,
    "mosaic": 1.0
  },
  "note": "2026-09 实测:夜间对抗赛录像验证,明度抖动 0.8 比默认 mAP +2"
}
```

- `name`:预设名(下拉框显示,建议带场景+验证状态)
- `imgsz`:该场景建议的训练分辨率
- `values`:只需写与官方默认不同的参数
- `note`:来源与验证结论(问学长/问AI的结论/实测数据),积累的价值就在这里

## 积累流程建议

1. 新场景先在工作台里调参数、看预览
2. 导出 JSON → 放进本目录 → 重启工作台验证出现在下拉框
3. 实际训练后把结论(涨没涨点)补进 `note`
4. 没验证过的参数组合不要直接当预设,标注"未验证"

场景痛点与算法的对应关系见 [YOLO训练参数手册](../../30_Knowledge/computer-vision/YOLO训练参数手册.md)。
